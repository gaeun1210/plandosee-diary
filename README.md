# 플랜두씨 다이어리

계획(Plan) → 실제로 한 일(Do) → 돌아보기(See)가 서버의 PostgreSQL 데이터베이스로 이어지는 다이어리입니다.
로그인은 아직 없습니다(과제 7에서 잠급니다). 첫 화면 맨 위에 공개 안내가 적혀 있습니다.

## 구조

```
server.js                   Express 서버 + API (DB 접속 문자열은 환경변수로만)
api/index.js                Vercel 서버리스 함수 입구 (server.js를 그대로 씀)
vercel.json                 Vercel 설정 (화면 폴더·서울 지역·보안 헤더)
db/schema.sql               표·제약·트리거 (서버 시작 때 자동 적용, 여러 번 실행해도 안전)
contracts/pds-schema-v2.json 표·항목·관계·날짜 규칙·집계 규칙
public/                     화면 (연두 노트 표지 디자인, 그림은 public/img/)
scripts/double-complete.sh  완료 요청 2개를 동시에 보내는 시험
render.yaml                 Render 배포 설정
```

## 배포 (무료, 결과물·소스 모두 로그인 없이 열림)

1. **DB 만들기 — Supabase** (Neon도 가능, 둘 다 PostgreSQL)
   - Supabase: New project(지역 Seoul) → 데이터베이스 비밀번호를 정해 따로 적어 둡니다 → 위쪽 **Connect** → **Direct** 탭 → 방식 **Session pooler**의 주소(`postgresql://postgres.xxxx:[YOUR-PASSWORD]@aws-…pooler.supabase.com:5432/postgres`)를 복사하고 `[YOUR-PASSWORD]`를 그 비밀번호로 바꿉니다.
   - Neon을 쓰면 Connection string(`…?sslmode=require`)을 복사하고 `PGSSL`은 넣지 않습니다.
   - 이 주소가 비밀값입니다. 어디에도 붙여 넣지 말고 3번의 환경변수 칸에만 넣습니다.
2. **소스 올리기 — GitHub 공개 저장소**: 이 폴더 안의 파일을 올립니다(`.env`는 `.gitignore`에 있어 올라가지 않습니다).
3. **사이트 띄우기 — Vercel**: Add New → Project → GitHub 저장소 Import → Framework Preset **Other** → Environment Variables에
   `DATABASE_URL`(1번 값)과 `PGSSL`=`no-verify`(Supabase일 때)를 넣고 Deploy.
   `vercel.json`이 화면 파일(`public/`)과 서버 함수(`api/index.js`), 서울 지역(icn1), 보안 헤더를 알아서 설정합니다.
4. 배포 주소(`https://….vercel.app`)를 새 시크릿 창에서 엽니다. 표는 첫 요청 때 자동으로 생깁니다.

> Render처럼 서버를 계속 켜 두는 곳에 올려도 됩니다(`render.yaml`, Start `npm start`). 이때도 환경변수는 같습니다.

내 컴퓨터에서 돌리려면: `cp .env.example .env` → 값 채우기 → `npm install` → `npm run dev` → http://localhost:3000

## 내 자료 넣기 (카드 5)

남의 예시가 아니라 **지금 실제로 하고 있는 일**을 넣습니다. 남이 봐도 괜찮은 내용만, 다른 사람 이름·연락처는 넣지 않습니다.

- 계획 1개 이상 → 한 번 고쳐서 "고친 이력 보기"에 1판·2판이 같이 보이게
- 그 계획에 딸린 할 일 5개 이상 (마감일·우선순위·태그·예상 시간 모두)
- 실행 기록 3개 이상 (그중 하나는 막혔던 이유를 적기, 하나는 마감이 지난 할 일로 두면 지연 수도 0이 아님)
- 돌아보기에서 고칠 점 한 줄 저장 → "다음 계획으로 넘기기"

### 비밀값 점검 (C58)

```bash
git log -p --all | grep -nE "postgres(ql)?://|npg_|sslmode" || echo "Git 기록 깨끗"
grep -rnE "postgres(ql)?://" public/ || echo "배포되는 화면 파일 깨끗"
```
브라우저 개발자 도구에서 Network 응답(특히 `/api/export`)과 Console에 접속 문자열이 없는지, 일부러 잘못된 값을 보내 본 오류 응답에도 없는지 봅니다.
오류 응답은 서버가 정해진 한국어 문장만 돌려주도록 되어 있습니다.

## 더한 기능

- **타이머:** 할 일의 "⏱ 시작" → 아래 거북이 알약에서 "정지" → 시작·끝 시각과 걸린 분이 실행 기록으로 저장. 한 번에 하나만 돌고, 새로고침·다른 기기에서도 이어집니다(서버에 저장).
- **칸반 보드:** 할 일 화면의 "보드". 진행 중·지연·완료 칸. 완료 칸으로 끌어다 놓으면 완료, 밖으로 빼면 되돌리기. 완료는 목록과 같은 API라 중복 방지 규칙(C21)이 그대로 적용됩니다.
- **캘린더:** 할 일 화면의 "캘린더". 마감일 칸에 할 일, 실행 기록이 있는 날은 한 일 분을 표시. 할 일을 누르면 목록의 그 할 일로 이동.

## 디자인 (연두 노트 표지)

- 책상 위에 연두색 노트 한 권이 놓인 모습입니다. 왼쪽 **책등**에 내 계획 목록, 오른쪽 가장자리 **인덱스 탭**(홈·계획·할 일·기록·돌아보기)으로 화면을 바꿉니다.
- 종이는 위쪽 연두에서 아래쪽 흰색으로 옅어지는 물방울 무늬입니다. 책등 위에는 거북이·네잎클로버·별 참이 달린 사슬이 살랑 흔들립니다.
- 홈: 리본 책갈피가 달린 **이름표**에 지금 계획, 그 아래 줄 친 칸에 기간·진행·고칠 점, 거북이 얼굴 손잡이가 달린 진행 막대, **오늘의 산책길**(체크할 때마다 거북이가 한 걸음씩 걸어가 네잎클로버에 도착).
- 클립이 꽂힌 **메모지**에 오늘 할 일(알록달록 네모 체크), 별무늬 **행운 쪽지** 카드, 하트 라벨 띠의 돌아보기 숫자.
- 공개 안내 문장은 모든 화면 맨 위 하트 라벨 띠에 있습니다.
- **그림 출처: 모두 AI로 만든 그림입니다.**
  - 거북이(`turtle-top.png`, `turtle-sleep.png`)와 포춘쿠키(`cookie-closed.png`, `cookie-open.png`): 이미지 생성 AI로 만든 그림을 잘라 배경을 지우고 색을 조금 맞췄습니다.
  - 별·Luck 꼬리표·클로버 단추 띠(`public/img/*.svg`)와 네잎클로버·아이콘(화면 안 SVG): AI(Claude)가 코드로 그린 그림입니다.
- 글꼴은 제목 Jua, 본문 Noto Sans KR.
- 홈의 포춘쿠키를 누르면 쿠키가 열려 행운 쪽지가 나오고, 문장이 바뀝니다.
- 휴대폰에서는 탭이 위쪽 가로 줄로 바뀌고 카드가 한 줄로 쌓입니다. "동작 줄이기"를 켜면 움직임이 꺼집니다.
